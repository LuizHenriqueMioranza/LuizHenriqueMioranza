# 🚀 Mostruários para negócios locais

Coleção de quatro landing pages desenvolvidas para demonstrar habilidade em criação de sites comerciais modernos e responsivos.

| Projeto | Proposta | Tecnologias |
|---|---|---|
| [💈 Brutus Barbearia](./barbearia/) | Visual forte e agendamento via WhatsApp | HTML, CSS e JavaScript |
| [⚡ Pulse Training](./academia/) | Captação de alunos e exibição de planos | HTML, CSS e JavaScript |
| [🍝 Oliva Cucina](./restaurante/) | Menu gastronômico e reserva demonstrativa | HTML, CSS e JavaScript |
| [✨ Aura Estética](./estetica/) | Serviços e conversão pelo WhatsApp | HTML, CSS e JavaScript |

## Objetivos praticados

- HTML semântico e acessibilidade básica
- Responsividade com CSS Grid, Flexbox e media queries
- Interatividade em JavaScript puro
- Organização profissional de pastas e documentação
- Interfaces orientadas à conversão de negócios locais

Cada projeto possui documentação própria e comentários no código. As marcas, preços, telefones e conteúdos são fictícios e foram usados somente para fins de portfólio.
