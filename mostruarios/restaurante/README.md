# 🍝 Oliva Cucina

Site fictício para um restaurante italiano contemporâneo, com narrativa visual, menu e reserva demonstrativa.

## Tecnologias

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white) ![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white) ![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=for-the-badge&logo=javascript&logoColor=black)

## Funcionalidades

- Menu gastronômico com imagens e preços
- Formulário demonstrativo de reserva
- Layout editorial responsivo
- Menu mobile e navegação suave

## Como executar

Abra `index.html` em qualquer navegador moderno. As imagens são carregadas do Unsplash e a reserva não envia dados reais.

> Projeto demonstrativo criado para o portfólio de Luiz Henrique Mioranza.
