# 💈 Brutus Barbearia

Landing page comercial fictícia para uma barbearia premium, desenvolvida com foco em conversão e experiência mobile.

## Tecnologias

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white) ![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white) ![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=for-the-badge&logo=javascript&logoColor=black)

## Funcionalidades

- Layout responsivo e menu mobile
- Catálogo de serviços e preços
- CTA de agendamento via WhatsApp
- Design premium, navegação suave e efeitos de interação

## Como executar

Baixe os arquivos e abra `index.html` no navegador. Antes de usar comercialmente, substitua o número fictício do WhatsApp e os textos do negócio.

> Projeto demonstrativo criado para o portfólio de Luiz Henrique Mioranza.
